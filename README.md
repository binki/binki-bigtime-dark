Dark theme for BigTime.

BigTime used to have a Dark theme. It still has a [support article](https://help.bigtime.net/hc/en-us/articles/23665750601751) ([archive](https://web.archive.org/web/20260812193103/https://help.bigtime.net/hc/en-us/articles/23665750601751-Switching-Between-Vibrant-Mode-and-Dark-Mode)) which gives invalid instructions on how to switch to the dark theme. Since 2026-08-10, BigTime only has a super bright white theme.

This script provides a dark theme which activates if your system is set to dark mode. This is a OLED-style (black is true black, foreground is grey) theme.
